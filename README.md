# NextPlay

NextPlay é um MVP de uma plataforma para descoberta de filmes, construído com foco em ser o sucessor do TV Time.

## Como Executar

1. Adicione sua chave da API do TMDB no arquivo `.env`:
   `VITE_TMDB_API_KEY=sua_chave_aqui`
2. Instale as dependências:
   `npm install`
3. Execute o servidor de desenvolvimento:
   `npm run dev`

## Tecnologias e Restrições Atendidas
- Vite + React (JavaScript, sem TS)
- Roteamento com `react-router-dom` v6
- CSS Puro (index.css)
- Funcionais componentes, props, children
- Uso de `Math.random()`, `Math.floor()`, `Math.round()`
- LocalStorage para Minha Lista
- Chamadas de API usando `fetch` e `async/await`
- `lucide-react` para ícones
